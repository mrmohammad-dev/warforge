# WarForge

**Forged for Battle — ساخته‌شده برای نبرد**

WarForge is an AI-assisted tank combat game project, starting with a small playable Android prototype and growing through tested, incremental releases.

## Vision

Build an original combined-arms combat game inspired by the depth of vehicle combat games. The long-term vision may include tanks, aircraft, naval vehicles, and online multiplayer.

## First playable milestone

- Unity 6 with Universal Render Pipeline (URP)
- Android landscape orientation
- Third-person camera
- Tank movement and turning
- Rotating turret and aiming
- Projectile firing
- A small test arena
- One simple target
- Touch controls and restart functionality

## Development principles

- Build the smallest playable version first.
- Test every meaningful change.
- Keep the project documented and version-controlled.
- Never claim a feature works without testing it.
- Prefer original or properly licensed assets.
- Do not commit passwords, API keys, tokens, or other secrets.
